{{ example.description }}

This hands-on example is based on the open-source Lipid Management project based on VA/DoD guidelines, which includes CQL libraries and value sets for lipid therapy decision support on FHIR R4, including PREVENT-aligned cardiovascular risk utilities and ValueSet resources.

These libraries are provided as teaching and demonstration artifacts. OpenCVDRisk is an open-source implementation of published PREVENT equations in Clinical Quality Language (CQL) and is not affiliated with or endorsed by the AHA. CDS outputs are not treatment orders. Not for clinical use.

Libraries

Each FHIR CQL Library is independently evaluable in Patient context, with upper guideline Library reusing the lower-level logic.

Library Role
BMI Height, weight, and BMI from Observations (computed BMI preferred with recorded BMI fallback)
SDI2019 ZIP / ZCTA to Robert Graham Center 2019 Social Deprivation Index decile (1-10)
OpenCVDRisk AHA PREVENT 10- and 30-year total CVD risk from chart labs, vitals, meds, and optional add-ons.
LipidManagement VA/DoD 2025 lipid CPG algorithm path and recommendation applicability on top of PREVENT risk.
How the libraries stack

BMI is used by OpenCVDRisk, which is in turn used by LipidManagement, with SDI2019 supplying optional scoring covariates using social deprivation index data.
